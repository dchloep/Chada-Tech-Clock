# Chada Tech Clock

This project is a C++ application that displays the current time in both 12-hour and 24-hour formats. The program provides an interactive menu that allows the user to add one hour, one minute, or one second to the displayed time.

## Features

- Displays time in both 12-hour and 24-hour formats
- Allows the user to add one hour
- Allows the user to add one minute
- Allows the user to add one second
- Automatically handles changes between AM and PM
- Uses an interactive menu for user input

## Technologies Used

- C++
- Visual Studio

## What I Learned

This project helped me practice using functions, loops, conditional statements, user input, and output formatting in C++. I also gained experience breaking a larger program into smaller functions to make the code easier to read and maintain.

## Project Purpose

This project was created as part of my Software Engineering coursework. The goal was to create a functional clock application while following programming best practices and writing organized, readable code.
